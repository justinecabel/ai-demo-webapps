# Sites

An unbranded directory of public sites, with categories and thumbnail previews.

Hosted on GitHub Pages. No Vercel backend is required.

Automatic imports are managed by a scheduled task in the connected Codex desktop conversation, not by an undocumented ChatGPT API or browser cookies. Only public, active, published Sites are included. The task checks every six hours while the computer and desktop app are running. It updates the public catalog and local JPEG thumbnails, preserving the frontend and unrelated repository files.

Enable Pages in Settings → Pages with source main / (root).
